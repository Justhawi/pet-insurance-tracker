ښ�️ How the Live Data System Works

The tracker pulls real scores directly from Trustpilot and Google Maps every day using a Python script that runs on your computer. After each fetch it rewrites this HTML file with the fresh numbers, so every time you open it the data is current.

1️⃣
One-time Setup
Double-click 1_SETUP.bat — it installs Python packages (requests, BeautifulSoup, Playwright) and downloads a headless Chromium browser for Google Maps. Takes ~2 minutes.
2️⃣
Daily Manual Run
Double-click 2_RUN_DAILY_UPDATE.bat any time you want fresh data. It fetches all 145 companies (~8-12 min) and auto-opens this file when done.
3️⃣
Automatic Daily Schedule
Import 3_SCHEDULE_DAILY.xml into Windows Task Scheduler (Start → search "Task Scheduler" → Action → Import Task). Runs at 8:00 AM every morning automatically.
📁 Files in your tracker folder
fetch_live_data.py Python script — fetches Trustpilot + Google Maps, recalculates all scores
1_SETUP.bat Run once to install all dependencies
2_RUN_DAILY_UPDATE.bat Double-click to fetch fresh data any time
3_SCHEDULE_DAILY.xml Import into Windows Task Scheduler for automatic 8AM daily runs
companies_data.json Latest data snapshot (auto-updated each fetch)
fetch_log.txt Detailed log of every fetch — check here if something goes wrong
💡 What gets fetched
Trustpilot — score (1–5) and total review count, scraped directly from trustpilot.com using the page's structured data.
Google Maps — score (1–5) and review count, scraped via a headless Chromium browser that navigates Google Maps search results.
Ponderated score — (TP_score × TP_reviews + G_score × G_reviews) ÷ (TP_reviews + G_reviews) — weighted by volume.
Average score — (TP_score + G_score) ÷ 2 — simple mean.
If a company has no Google Maps listing, the script keeps the previous value and the table shows the source link instead.
